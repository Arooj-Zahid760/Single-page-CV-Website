# Single-Page CV Website
<br>
A simple and professional single-page CV website created using HTML5.
<br>
The website presents personal and professional information in a clear and structured format.
<br>
## 📌 Project Overview
<br>
This project is a single-page CV website developed as a web development assignment. 
It demonstrates the use of HTML5 to structure and organize personal information, education, experience, skills, and professional profile links on a single webpage.
<br>
## ✨ Features
<br>
- Personal information
<br>
- Contact information
<br>
- Education details
<br>
- Experience section
<br>
- Skills section
<br>
- LinkedIn profile link
<br>
- GitHub profile link
<br>
- Structured single-page layout
<br>
- Simple and accessible design
<br>

## 🛠️ Technology Used
